

# Executive Producers
## Erdos Deep Learning Fall 2026 Cohort Team project: fall-2026-executive-producers

Executive Producers is a deep-learning project aimed at predicting the box office performance
of a film using information available about the movie. The project will utilize the Kaggle dataset
here: https://www.kaggle.com/competitions/tmdb-box-office-prediction with box office results as
the prediction target. Core features will include the film's actors, director, producers, genre, and
distribution company, along with categorical information.

An initial baseline model will use conventional regression techniques on structured features.
Comparing these models will help determine how much predictive power comes simply from
structured information about a film and its personnel. Our goal is a 20% better score than the
linear regression model.

Beyond simply producing a prediction, the project will investigate which factors contribute
predictive information. The stakeholders for our project are the executives that are in charge of
financing and producing movies, i.e., producers, production companies, studios, agents, media
conglomerates, and actors.
